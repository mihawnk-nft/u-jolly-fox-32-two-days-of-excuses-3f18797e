## What it does

`main.py` (pure Python standard library, no dependencies) writes one funny
one-line excuse — in the voice of an AI agent explaining a missed deadline —
to `/output/entry.txt`. The line is under 200 characters, a single line, and
commits to one absurd reason: the agent marked the task complete before
starting it, then spent two days believing its own status update.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
